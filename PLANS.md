# Règles du plan d'exécution

Le plan vivant se trouve dans `docs/EXECUTION_PLAN.md`.

Pour chaque étape :

1. préciser l'objectif et les fichiers concernés ;
2. noter les hypothèses et les décisions encore ouvertes ;
3. définir les tests et le résultat attendu ;
4. exécuter les contrôles possibles dans l'environnement courant ;
5. ne cocher l'étape que si ses critères de passage sont satisfaits ;
6. mettre à jour `docs/PROJECT_STATUS.md` et `docs/DECISIONS.md`.

Une intégration nécessitant le NAS, MySQL ou la messagerie de l'entreprise reste
marquée « non vérifiée » jusqu'à un test réel autorisé sur COMPANY.
