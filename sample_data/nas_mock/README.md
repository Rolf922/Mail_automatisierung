# Faux NAS HOME

Ce dossier simule le NAS uniquement avec des données synthétiques.

Les PDF ne sont pas inclus dans le paquet de transfert. Pour créer le PDF
d'exemple localement, depuis la racine du projet :

```powershell
python scripts/create_sample_pdf.py
```

Ne jamais placer ici un Prüfprotokoll client destiné à Git ou au paquet HOME.
